# SACI Zhour - Portfolio

A responsive personal portfolio built with **HTML5, CSS3 and vanilla JavaScript**

The interface design imitates a minimilistic retro desktop *file explorer* window.

The websites presents who i am, my education, my skills, my projects and how to contact me; each in a seperate section. Following a semantic HTML structure, a clean CSS interface that adapts to desktop, tablet and smartphone, and JavaScript interactivity.



## Implemented features

- **Home**: greeting with a looping typewriter effect, name and tagline, two call-to-action buttons, and a profile photo framed like a window with floating code stickers.
- **About**: a short introduction and my education.
- **Skills**: HTML5, CSS3, JavaScript, Python, React and Tailwind, shown as tiles with their logos.
- **Projects**: three project cards (Personal Portfolio, Amanah, Thiqa) with screenshots, descriptions and technology or role tags.
- **Contact**: a message form and my contact details (email, GitHub, LinkedIn).


## Technologies used


| Technology | Use |
|---|---|
| **HTML5** | Semantic page structure and form |
| **CSS3** | Variables, Flexbox, Grid, media queries,  animations |
| **JavaScript** | DOM manipulation, events, `IntersectionObserver`, `matchMedia`, form validation |
| **Git and GitHub** | Version control and hosting of the code |
| **VS Code, Live Server, Prettier** | Editing, live preview, formatting |
| **Chrome DevTools, W3C validators** | Testing and debugging |
| **Vercel** | Deploying |
